void sun::codegen::DebugInfoBuilder::attachExpressionLocation(llvm::IRBuilderBase &builder, const sun::support::Position &loc)

Set the builder's debug location for the expression about to be emitted: scoped to the insert-point function's subprogram, or cleared when that function has none.

clearLocation

public · function · Source (opens in a new tab)

void sun::codegen::DebugInfoBuilder::clearLocation(llvm::IRBuilderBase &builder)

Drop the builder's debug location.

Required when switching the insert point into a function that has no subprogram (wrappers, init functions): such functions must carry no debug locations at all.

pushLexicalBlock

public · function · Source (opens in a new tab)

bool sun::codegen::DebugInfoBuilder::pushLexicalBlock(llvm::IRBuilderBase &builder, const sun::support::Position &loc)

Open a DILexicalBlock under the current scope so variables declared in source blocks (if/else, loops, try/catch) get block-accurate visibility.

Returns true when a block was pushed (caller must pair with popLexicalBlock); false when disabled or the insert point is in a function without a subprogram.

Related: sun::support::Position
