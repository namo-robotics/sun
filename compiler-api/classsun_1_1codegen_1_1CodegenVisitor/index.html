public · function · Source (opens in a new tab)

template <typename T>
llvm::Value * sun::codegen::CodegenVisitor::codegen(const T &)=delete

A node kind whose codegen lives on a component must be dispatched to that component.

Without this, the missing overload would bind to codegen(const ExprAST&) instead — which re-enters the dispatch switch and recurses until the stack runs out. Make it a compile error instead.
