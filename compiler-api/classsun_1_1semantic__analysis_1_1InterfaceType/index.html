class sun::semantic_analysis::InterfaceType : public sun::semantic_analysis::NominalType

Interface type for user-defined interfaces Interfaces define a contract that classes must implement.

toLLVMType

public · function · Source (opens in a new tab)

llvm::Type * sun::semantic_analysis::InterfaceType::toLLVMType(llvm::LLVMContext &ctx) const override

Interfaces are represented as fat pointers: { ptr data, ptr vtable }.

The vtable contains method pointers followed by concrete drop glue (or a no-op for a borrow), so an owning interface remains two pointers.
