sun::ast::GenericCallAST

class · Source (opens in a new tab)

class sun::ast::GenericCallAST : public sun::ast::ExprAST

Generic function call: create<Type>(args...) or create<Type1, Type2>(args...) Used for generic free functions like create<T>, destroy, etc.
