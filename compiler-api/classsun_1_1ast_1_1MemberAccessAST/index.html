sun::ast::MemberAccessAST

sun::ast::MemberAccessAST

class · Source (opens in a new tab)

class sun::ast::MemberAccessAST : public sun::ast::ExprAST

Member access expression: object.fieldName or object.methodName For method calls, this is wrapped in CallExprAST For generic method calls like object.method<T>(), typeArguments will be populated.
