make

public · function · static · Source (opens in a new tab)

static Token sun::parsing::Token::make(TokenKind k, const sun::support::Position &s, const sun::support::Position &e)

Generic factory for simple tokens (uses lookup table).

Indexes a flat array rather than searching getTokenInfo()'s std::map: this runs once per operator/keyword/punctuation token, and a red-black tree walk per token was measurable in the lexer's profile.

Related: Token, TokenKind, sun::support::Position, getTokenInfo()
