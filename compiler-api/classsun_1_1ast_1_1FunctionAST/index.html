isCExtern

public · function · Source (opens in a new tab)

bool sun::ast::FunctionAST::isCExtern() const

True only for extern function — a C symbol linked by its exact name, with no module scope.

declare function is a forward declaration of a Sun function and keeps the symbol derived from its declaration, so the two must not be conflated even though both are bodyless.
