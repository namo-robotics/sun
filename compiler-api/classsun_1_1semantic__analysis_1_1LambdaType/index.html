acceptsValueOf

public · function · Source (opens in a new tab)

bool sun::semantic_analysis::LambdaType::acceptsValueOf(const LambdaType &from) const

Can a by-value 'from' argument bind to a parameter of this type?

Same signature, and each marker only widens: a non-throwing lambda may go where a throwing one is expected, and an environment-free lambda may go where a '<'_>' one is expected — never the other way around.

equalsIgnoringThrow

public · function · Source (opens in a new tab)

bool sun::semantic_analysis::LambdaType::equalsIgnoringThrow(const LambdaType &other) const

Same signature ignoring throwing-ness and the lifetime marker.

Used by the bound-method overload chooser, which picks a method by shape before the chosen value is flagged as frame-bound; assignability rejects it later.
