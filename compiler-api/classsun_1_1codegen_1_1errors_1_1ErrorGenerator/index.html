llvm::Value * sun::codegen::errors::ErrorGenerator::codegen(const T &)=delete

A node kind with its own overload must not silently bind to the ExprAST forwarder above: that path attaches an expression debug location, so a block routed through it changes DWARF output.

Make it a compile error instead. Add an overload here when a new kind is needed.

llvm::Value * sun::codegen::errors::ErrorGenerator::emitPossiblyThrowingCall(llvm::FunctionType *fnTy, llvm::Value *callee, llvm::ArrayRef< llvm::Value * > args, bool canThrow, const llvm::Twine &name)

Emits a call that may unwind.

If canThrow and we are inside a try block, emits an invoke unwinding to the innermost try's landing pad and continues codegen in the normal-destination block; otherwise emits a plain call.
