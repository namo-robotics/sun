attachDocComments

public · function · Source (opens in a new tab)

void sun::parsing::attachDocComments(sun::ast::BlockExprAST &program, const std::string &source)

Store the doc comment of every declaration in the program on its node — functions, classes and their fields and methods, interfaces, enums and their variants, module-level variables — so it travels with the tree into .moon bundles and reaches editor tooling without the source at hand.

Attaches source documentation to declarations in a parsed program.

Related: sun::ast::BlockExprAST

compoundToBinaryOp

public · function · Source (opens in a new tab)

std::optional< TokenKind > sun::parsing::compoundToBinaryOp(TokenKind kind)

Map compound-assignment token kinds (+=, -=, ...) to the underlying binary operator; nullopt for anything else.

Shared by the parser, semantic analysis, and codegen.

Related: TokenKind

decodeUtf8

public · function · Source (opens in a new tab)

std::optional< uint32_t > sun::parsing::decodeUtf8(std::string_view s, int &length)

Decode the UTF-8 sequence at the start of s.

Returns the scalar value and writes the number of bytes consumed to length, or nullopt if the bytes are not well-formed UTF-8 (bad continuation byte, overlong form, surrogate, or out of range).

Encode scalar as UTF-8 into out (at least 4 bytes).

Returns the number of bytes written.

formatProgram

public · function · Source (opens in a new tab)

std::string sun::parsing::formatProgram(const sun::ast::BlockExprAST &program, const std::map< int, sun::parsing::Comment > &comments, const std::string &source)

Format an already-parsed lossless (pre-lowering) program.

Formats a parsed program with its original comments and source context.

comments must come from the same parse (Parser::getComments()) and source must be the exact text that was parsed — literals and types are sliced from it.

Related: sun::ast::BlockExprAST, sun::parsing::Comment, Parser::getComments()

formatSource

public · function · Source (opens in a new tab)

std::string sun::parsing::formatSource(const std::string &source, const std::string &filePath="<fmt>")

Parse source and reprint it in the canonical style (2-space indent, K&R braces, comments preserved).

Parses and formats Sun source text for the supplied file.

Throws SunError on parse failure; the input is never partially formatted.

Related: SunError

getKeywordSpelling

public · function · Source (opens in a new tab)

std::optional< std::string_view > sun::parsing::getKeywordSpelling(TokenKind kind)

The spelling of a keyword token (a token whose regex is a bare word, so it would otherwise lex as an identifier); nullopt for any other kind.

Derived from the regex table so a new keyword is covered without a second list.

Related: TokenKind

normalizeBody

public · function · static · Source (opens in a new tab)

static void sun::parsing::normalizeBody(std::unique_ptr< ExprAST > &slot, bool isIfBody)

Normalize an if/loop body block to the shape the core pipeline expects: empty block -> synthetic literal, single-statement block -> the statement.

The parser keeps bodies as blocks for losslessness.

std::optional< char > sun::parsing::simple(char c)

Handles newline, tab, carriage return, backslash, and null escapes.

Returns the character the escape stands for, or nullopt if c does not name one of them (the caller decides what to do with quotes and hexadecimal or Unicode escapes).
