exprDiverges

public · function · Source (opens in a new tab)

bool sun::ast::exprDiverges(const ExprAST &expr)

True when control never falls out of expr: it ends in a return or a throw, or is an if whose branches all do.

Reports whether evaluating this expression always exits the current control-flow path.

Whatever such an expression did cannot reach the code that follows it, so a pass that carries state forward should leave it behind.

Related: ExprAST

forEachChild

public · function · Source (opens in a new tab)

void sun::ast::forEachChild(const ExprAST &node, const ChildFn &fn)

Calls fn for each direct child expression of node, in source order.

Visits each directly owned expression child of a syntax node.

Unlike ExprAST::forEachChildSlot (a rewriting hook that forwards through strongly typed children), this visits every child, including function bodies, class and interface methods, slice bounds, match patterns and struct literal values. Used by tooling that walks the tree (language server lookups).

Related: ExprAST, ChildFn, ExprAST::forEachChildSlot

BlockKind

public · enum · Source (opens in a new tab)

enum class sun::ast::BlockKind

Which construct a block is the body of.

In the language, only two kinds evaluate to their last statement — a match arm's body and an unsafe block's body. Every other kind is a statement body whose trailing expression is not a value; in value position, { ... } always means a struct literal, never a block. The one exception is Value, which has no syntax at all: it is what the compiler's own lowerings make when they need a block that carries a value (string interpolation).
