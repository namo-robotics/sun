sun::ast::TypeAnnotation

struct · Source (opens in a new tab)

struct sun::ast::TypeAnnotation

Type annotation structure for parsed type info Supports: i32, f64, bool, void, ptr<T>, ref T, function, lambda Generic types: ClassName<T, U> for class instantiation Array types: array<T, N> or array<T, M, N> for fixed-size arrays Error union types: T, error (value or error).
