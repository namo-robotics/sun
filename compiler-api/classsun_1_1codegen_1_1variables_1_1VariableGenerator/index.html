Value * sun::codegen::variables::VariableGenerator::tryCodegenAddress(const ExprAST &expr)

The storage address of an assignable expression.

tryCodegenAddress returns nullptr for shapes with no addressable slot (class index targets, slices, closure captures, temporaries); codegenAddress throws instead. Neither ever spills a value to a temporary alloca.
