# Runtime & Errors

Part of the [Sun ABI draft](/abi). These are proposed requirements, not guarantees
of current releases. Open decisions must be resolved before stabilization.

## Runtime, errors, and global state

| Subject | Level | Requirement |
| --- | --- | --- |
| Runtime entry points | MUST | Version the contracts used by compiled code, including argument and result representations, ownership, and failure behavior. |
| Symbol resolution | MUST NOT | Silently select an incompatible implementation when bundles use the same runtime symbol. |
| Error propagation | MUST | Define exception objects, type identification, matching, cleanup, and unwinding. |
| Unwinding | MUST | Allow unwinding across a boundary only when both sides support its contract. |
| Cross-bundle errors | MUST | Specify throwing and catching across bundles, or explicitly reject unsupported throwing boundaries. |
| Global initialization | MUST | Initialize dependencies before consumers and each deduplicated global instance exactly once. |
| State lifecycle | MUST | Define shutdown order, initialization failure, thread-local state, and state shared among bundles. |
| Process-wide state | MUST NOT | Duplicate state defined as process-wide when bundling several runtime implementations. |

## Open decisions

List emitted runtime symbols and specify exception machinery, type-ID collision
handling, startup, teardown, and thread-local storage.
